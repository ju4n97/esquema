# Quickstart

This guide walks through creating an HCL manifest, starting the HTTP service, and testing its endpoints.

<Steps>

### 1. Create a manifest

Create a project directory and an `app.hcl` file:

```bash
mkdir hclapi-quickstart && cd hclapi-quickstart
touch app.hcl
```

Paste the following configuration:

```hcl
server {
  host = "127.0.0.1"
  port = 8080
}

route "GET /health" {
  respond {
    status = 200
    body = {
      status    = "healthy"
      timestamp = now()
    }
  }
}

route "POST /transform" {
  starlark "sanitize" {
    source = <<-STARLARK
      def execute(ctx):
        body = ctx["request"]["body"]
        prefix = body.get("prefix", "item")
        raw_tags = body.get("tags", [])
        cleaned = [prefix + ":" + t.strip().lower() for t in raw_tags if len(t.strip()) > 0]
        return {"count": len(cleaned), "tags": cleaned}
    STARLARK
  }

  respond {
    status = 200
    body   = steps.sanitize.result
  }
}
```

`GET /health` returns an ISO timestamp. `POST /transform` cleans up string tags inside a sandboxed Starlark script and streams the result.

### 2. Start the server

Run the server pointing to the manifest:

```bash
hclapi serve app.hcl
```

Output:

```text
time=2026-09-18T07:00:00.000Z level=INFO msg="compiling hclapi manifests" targets=["app.hcl"]
time=2026-09-18T07:00:00.001Z level=INFO msg="server listening" addr="127.0.0.1:8080" routes=2 connections=0
```

### 3. Call the endpoints

Call the health route:

```bash
curl -i http://localhost:8080/health
```

```http
HTTP/1.1 200 OK
Content-Type: application/json; charset=utf-8

{"status":"healthy","timestamp":"2026-09-18T12:00:00Z"}
```

Call the transform route with a payload:

```bash
curl -i -X POST http://localhost:8080/transform \
  -H "Content-Type: application/json" \
  -d '{"prefix": "env", "tags": [" PROD ", "", "staging", " Dev "]}'
```

```http
HTTP/1.1 200 OK
Content-Type: application/json; charset=utf-8

{"count":3,"tags":["env:prod","env:staging","env:dev"]}
```

If you send malformed JSON, `hclapi` rejects it with an RFC 9457 `400 Bad Request` problem before the pipeline executes:

```bash
curl -i -X POST http://localhost:8080/transform \
  -H "Content-Type: application/json" \
  -d '{"prefix":'
```

```http
HTTP/1.1 400 Bad Request
Content-Type: application/problem+json

{"detail":"Malformed JSON request body","status":400,"title":"Bad Request","type":"urn:hclapi:error:bad-request"}
```

</Steps>
