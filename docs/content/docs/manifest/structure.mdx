# Files and structure

hclapi compiles its configuration from a single file, a folder, or glob patterns like `hclapi serve ./routes/**/*.hcl`.

## File discovery

When pointing hclapi at a directory, the loader finds all files ending in `.hcl`.

It automatically skips hidden files or folders starting with a dot, such as `.git` or `.vscode`. Non-manifest files like `.sql` or `.md` aren't loaded.

## The .hclapiignore file

Place a `.hclapiignore` file in your root folder to skip specific files or directories. It supports wildcard matching and negation patterns using `!`:

```text
# Skip temporary folders
scratch/

# Skip local configs
local.hcl

# Skip drafts but keep preview
drafts/*
!drafts/preview.hcl
```

## Environment variables

You can read environment variables during compile time using the `env` function:

```hcl
server {
  port = env("PORT", 8080)
}

connection "sql" "main" {
  engine = "postgres"
  source = env("DATABASE_URL", "postgres://localhost/main")
}
```

If a variable isn't set, it evaluates to an empty string.

## Merging rules and invariants

hclapi merges manifests across all discovered files into a single runtime configuration:

1. **Singleton blocks**: The `server`, `openapi`, and `telemetry` blocks are singletons. You can't declare `server` in more than one file across a project.
2. **Duplicate routes**: Endpoints are identified by method and path, such as `GET /users`. Declaring the exact same route pattern in two files halts boot immediately so you won't get runtime routing collisions.
3. **Shared namespace**: Connections and schemas share a single global namespace. A connection declared in `connections.hcl` is instantly available to routes declared in `routes/users.hcl`.

## Recommended project layout

```text
my-api/
├── .hclapiignore
├── server.hcl         # server {} and telemetry {}
├── connections.hcl    # connection pools
├── schemas/
│   └── user.hcl       # schema "User" {}
└── routes/
    ├── auth.hcl       # route "POST /auth" {}
    └── users.hcl      # route "GET /users" {}
```
