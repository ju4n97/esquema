# connection

The `connection` block declares external pools for relational databases and key-value stores.

## SQL connections

hclapi uses four canonical SQL engine names:

```hcl
connection "sql" "main" {
  engine = "postgres"
  source = "postgres://user:pass@localhost:5432/app?sslmode=disable"
  pool {
    max_open = 25
    max_idle = 25
  }
}
```

### Supported engines

| Engine          | Dialect placeholder | Default Go driver |
| :-------------- | :-----------------: | :---------------- |
| **`postgres`**  |      `$1, $2`       | `pgx`             |
| **`mysql`**     |         `?`         | `mysql`           |
| **`sqlite`**    |         `?`         | `sqlite`          |
| **`sqlserver`** |     `@p1, @p2`      | `sqlserver`       |

Aliases like `postgresql`, `pgx`, `sqlite3`, `mariadb`, or `mssql` aren't allowed. hclapi rejects non-canonical names during compilation so your manifests stay consistent across teams.

### Pool settings

| Attribute  | Type  | Default | Description                                  |
| :--------- | :---- | :------ | :------------------------------------------- |
| `max_open` | `int` | `25`    | Maximum active open connections in the pool  |
| `max_idle` | `int` | `25`    | Maximum idle connections waiting in the pool |

Idle connections are closed after 5 minutes, and active connections are recycled after 15 minutes.

## Valkey and Redis connections

```hcl
connection "valkey" "cache" {
  url = "valkey://127.0.0.1:6379"
}
```

| Attribute | Type     | Required | Description                                           |
| :-------- | :------- | :------: | :---------------------------------------------------- |
| `url`     | `string` |   yes    | Connection URL using `redis://user:pass@host:port/db` |
