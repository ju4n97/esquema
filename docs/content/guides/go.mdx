# Go integration

You can embed hclapi directly into an existing Go application as a standard library. It mounts on any standard `http.ServeMux` or third-party router (Chi, Echo, Gin), reuses managed connection pools, and lets you invoke custom Go functions directly from HCL pipelines.

## Installation

```bash
go get github.com/ju4n97/hclapi
```

## Embedding in an existing Go service

`*hclapi.Engine` implements standard `http.Handler`:

```go
package main

import (
	"context"
	"log"
	"net/http"
	"os"
	"os/signal"
	"syscall"
	"time"

	"github.com/ju4n97/hclapi"
)

func main() {
	// Load and compile manifests
	manifest, err := hclapi.Load("./routes/**/*.hcl")
	if err != nil {
		log.Fatalf("failed to compile manifests: %v", err)
	}

	// Initialize engine with custom step handlers and options
	app, err := hclapi.New(manifest,
		hclapi.WithStep("payments.charge", handlePayment),
	)
	if err != nil {
		log.Fatalf("failed to initialize hclapi: %v", err)
	}
	defer app.Close()

	// Mount onto a standard Go HTTP server
	srv := &http.Server{
		Addr:         ":8080",
		Handler:      app,
		ReadTimeout:  manifest.Server.ReadTimeout.Duration(),
		WriteTimeout: manifest.Server.WriteTimeout.Duration(),
	}

	stop := make(chan os.Signal, 1)
	signal.Notify(stop, os.Interrupt, syscall.SIGTERM)

	go func() {
		log.Println("server listening on :8080")
		if err := srv.ListenAndServe(); err != nil && err != http.ErrServerClosed {
			log.Fatalf("server crashed: %v", err)
		}
	}()

	<-stop
	shutdownCtx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
	defer cancel()
	_ = srv.Shutdown(shutdownCtx)
}

func handlePayment(ctx context.Context, req *hclapi.GoRequest) (any, error) {
	amount := req.Args.GetOr("amount", int64(0))
	return map[string]any{"charged": amount, "status": "success"}, nil
}
```

## Calling custom Go functions from manifests

Invoke registered Go callbacks using the `go` step keyword:

```hcl
route "POST /checkout" {
  go "process_charge" {
    use = "payments.charge"
    args = {
      amount = ctx.request.body.amount
    }
  }

  respond {
    status = 200
    body   = steps.process_charge.result
  }
}
```

Go step handlers use this signature:

```go
func(ctx context.Context, req *hclapi.GoRequest) (any, error)
```

The `*hclapi.GoRequest` struct exposes:

```go
type GoRequest struct {
    Name    string        // Step name declared in manifest
    Args    Args          // Evaluated arguments from HCL args map
    Request *http.Request // Raw standard *http.Request
}
```

## Working with `req.Args`

`req.Args` provides typed, panic-safe helpers with automatic type coercion:

```go
func handlePayment(ctx context.Context, req *hclapi.GoRequest) (any, error) {
    // Direct typed extraction with presence check
    currency, ok := req.Args.Get[string]("currency")
    if !ok {
        currency = "USD"
    }

    // Safe extraction with typed fallback
    amount := req.Args.GetOr("amount", int64(0))

    // Typed slice extraction
    tags := req.Args.Slice[string]("tags")

    // One-line struct binding
    type ChargeParams struct {
        Amount   int64  `json:"amount"`
        Currency string `json:"currency"`
    }
    var params ChargeParams
    if err := req.Args.Bind(&params); err != nil {
        return nil, err
    }

    return map[string]any{"id": "ch_123", "currency": currency, "amount": amount}, nil
}
```

## Returning RFC 9457 Problem Details from Go handlers

If a Go callback encounters a business logic error (e.g. payment failure), return an instance of `problem.Problem` to stream a structured error:

```go
func handlePayment(ctx context.Context, req *hclapi.GoRequest) (any, error) {
    if req.Args.GetOr("amount", int64(0)) <= 0 {
        return nil, problem.New(http.StatusBadRequest, "Charge amount must be positive")
    }
    return map[string]any{"success": true}, nil
}
```

## Accessing connection pools directly

Reuse database and cache connection pools configured in HCL manifests without opening duplicate pools:

```go
// Direct SQL access via *sql.DB
db, ok := app.SQL("main")
if ok {
    var email string
    _ = db.QueryRowContext(ctx, "SELECT email FROM users WHERE id = $1", 42).Scan(&email)
}

// Direct Valkey / Redis access via valkey.Client
cache, ok := app.Valkey("cache")
if ok {
    cmd := cache.B().Get().Key("session:user_42").Build()
    val, _ := cache.Do(ctx, cmd).ToString()
}
```

## Programmatic OpenAPI compilation

Generate the compiled OpenAPI 3.1 specification programmatically in tests or build scripts:

```go
spec, err := hclapi.CompileSpec(manifest)
if err != nil {
    log.Fatalf("spec compilation error: %v", err)
}

fmt.Printf("OpenAPI ETag: %s\n", spec.JSONETag)
_ = os.WriteFile("openapi.json", spec.JSON, 0o644)
_ = os.WriteFile("openapi.yaml", spec.YAML, 0o644)
```

## Graceful shutdown

Calling `app.Close()` cleanly shuts down all managed connection pools:

- Waits for active database connections to finish before closing pools.
- Closes all active Valkey clients.
- Closes idle outbound HTTP client connections.

```go
defer func() {
    if err := app.Close(); err != nil {
        log.Printf("error closing connection pools: %v", err)
    }
}()
```
