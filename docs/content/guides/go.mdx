# Go integration

You can embed hclapi directly into an existing Go application as a standard library. It mounts on any standard `http.ServeMux`, reuses managed connection pools, and lets you call Go code from your HCL routes.

## Installation

Add the module to your `go.mod`:

```bash
go get github.com/ju4n97/hclapi
```

## Embedding in an existing Go service

`*hclapi.Engine` implements Go's standard `http.Handler` interface, so you can pass it straight to `http.ListenAndServe` or mount it under an existing router:

```go
package main

import (
	"context"
	"log"
	"net/http"
	"os"
	"os/signal"
	"syscall"
	"time"

	"github.com/ju4n97/hclapi"
)

func main() {
	// 1. Load and compile manifests
	cfg, err := hclapi.Load("./routes/**/*.hcl")
	if err != nil {
		log.Fatalf("failed to compile manifests: %v", err)
	}

	// 2. Initialize engine with custom step handlers
	app, err := hclapi.New(cfg,
		hclapi.WithStep("payments.charge", handlePayment),
	)
	if err != nil {
		log.Fatalf("failed to initialize hclapi: %v", err)
	}
	defer app.Close()

	// 3. Mount onto a standard Go HTTP server
	srv := &http.Server{
		Addr:         ":8080",
		Handler:      app,
		ReadTimeout:  cfg.Server.ReadTimeout.Duration(),
		WriteTimeout: cfg.Server.WriteTimeout.Duration(),
	}

	stop := make(chan os.Signal, 1)
	signal.Notify(stop, os.Interrupt, syscall.SIGTERM)

	go func() {
		log.Println("server listening on :8080")
		if err := srv.ListenAndServe(); err != nil && err != http.ErrServerClosed {
			log.Fatalf("server crash: %v", err)
		}
	}()

	<-stop
	shutdownCtx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
	defer cancel()
	_ = srv.Shutdown(shutdownCtx)
}

func handlePayment(ctx context.Context, step *hclapi.Step) (any, error) {
	amount := step.Args.GetOr("amount", 0)
	return map[string]any{"charged": amount, "status": "success"}, nil
}
```

## Registering custom step handlers

In your HCL manifest, invoke the registered Go function by its key:

```hcl
route "POST /checkout" {
  step "go" "process_charge" {
    use = "payments.charge"
    args = {
      amount = ctx.request.body.amount
    }
  }

  respond {
    status = 200
    body   = steps.process_charge.result
  }
}
```

Go step handlers use this signature:

```go
func(ctx context.Context, step *hclapi.Step) (any, error)
```

The `*hclapi.Step` struct exposes:

```go
type Step struct {
    Name    string        // Step name declared in manifest
    Args    Args          // Evaluated arguments from HCL args map
    Request *http.Request // Full incoming standard HTTP request
}
```

## Argument extraction with step.Args

`step.Args` gives you typed, panic-safe helpers with automatic coercion:

```go
func handlePayment(ctx context.Context, step *hclapi.Step) (any, error) {
    // 1. Direct typed fetch with success flag
    currency, ok := step.Args.Get[string]("currency")
    if !ok {
        currency = "USD"
    }

    // 2. Safe extraction with typed fallback
    amount := step.Args.GetOr("amount", int64(0))

    // 3. Typed slice extraction
    tags := step.Args.Slice[string]("tags")

    // 4. Check presence
    if step.Args.Has("metadata") {
        // ...
    }

    return map[string]any{"id": "ch_123", "currency": currency, "amount": amount}, nil
}
```

## Struct binding with step.Args.Bind

If you've got multiple arguments, you don't need to extract them one by one. Bind the entire `args` map into a struct in one line:

```go
type ChargeParams struct {
    Amount   int64  `json:"amount"`
    Currency string `json:"currency"`
    TenantID string `json:"tenant_id"`
}

func handlePayment(ctx context.Context, step *hclapi.Step) (any, error) {
    var params ChargeParams
    if err := step.Args.Bind(&params); err != nil {
        return nil, err
    }

    return map[string]any{"charged": params.Amount, "tenant": params.TenantID}, nil
}
```

## Accessing raw HTTP request data

You can inspect the untouched standard `*http.Request` via `step.Request`:

```go
func handleCustomAuth(ctx context.Context, step *hclapi.Step) (any, error) {
    // Read raw headers
    authHeader := step.Request.Header.Get("Authorization")

    // Read client remote IP address
    clientIP := step.Request.RemoteAddr

    // Access route parameters extracted by Go's ServeMux
    accountID := step.Request.PathValue("id")

    return map[string]any{
        "authorized": authHeader != "",
        "ip":         clientIP,
        "account_id": accountID,
    }, nil
}
```

## Reusing database and cache pools

If your Go handlers need direct database access, you don't need to open secondary connection pools. You can access the exact database and cache clients configured by hclapi:

```go
// Direct SQL access via *sql.DB
db, ok := app.SQL("main")
if !ok {
    log.Fatal("database 'main' not configured")
}

var email string
err := db.QueryRowContext(ctx, "SELECT email FROM users WHERE id = $1", 42).Scan(&email)

// Direct Valkey / Redis client access via valkey.Client
cache, ok := app.Valkey("cache")
if ok {
    cmd := cache.B().Get().Key("session:user_42").Build()
    val, _ := cache.Do(ctx, cmd).ToString()
}
```

## Graceful shutdown

Calling `app.Close()` cleanly shuts down all managed connection pools:

- Waits for active database connections to idle before closing pools.
- Closes all active Valkey clients.

```go
defer func() {
    if err := app.Close(); err != nil {
        log.Printf("error closing connection pools: %v", err)
    }
}()
```
