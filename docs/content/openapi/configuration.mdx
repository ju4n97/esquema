# OpenAPI configuration

Configuring OpenAPI involves two parts:

1. **Global metadata**: Declared inside the root `openapi` block to set document titles, servers, and tags.
2. **Specification routes**: Declared using the `spec` step to serve JSON or YAML documents.

## Serving raw specifications

Mount endpoints using the `spec` step:

```hcl
route "GET /openapi.json" {
  spec {
    format = "json"
  }
}

route "GET /openapi.yaml" {
  spec {
    format = "yaml"
  }
}
```

### Attributes

| Attribute | Type     | Default  | Allowed values     | Description                   |
| :-------- | :------- | :------- | :----------------- | :---------------------------- |
| `format`  | `string` | `"json"` | `"json"`, `"yaml"` | Output serialization encoding |

## ETag caching

Specifications are compiled once at boot time and hashed with SHA-256.

Incoming requests containing a matching `If-None-Match` header receive an instant `304 Not Modified` response. The engine won't re-serialize or re-transmit the document when the client's cache is already fresh.

## Global metadata declaration

Declare the `openapi` block at the root of your manifest:

```hcl
openapi {
  title       = "Storefront API"
  version     = "1.2.0"
  description = "Customer account and order management services"

  servers =[
    {
      url         = "https://api.example.com/v1"
      description = "Production cluster"
    }
  ]

  tags = [
    {
      name        = "users"
      description = "Customer accounts and profiles"
    }
  ]

  contact {
    name  = "API Support"
    email = "support@example.com"
    url   = "https://example.com/support"
  }

  license {
    name = "Apache-2.0"
    url  = "https://www.apache.org/licenses/LICENSE-2.0"
  }
}
```

If you don't define a `server` block, hclapi defaults to `url = "/"`. This keeps the API origin relative so browser portals work without CORS issues.

## Exporting with the CLI

You can export the compiled specification directly to a file or standard output without starting the server:

```bash
# Print JSON to stdout
hclapi openapi -c .

# Save JSON specification to file
hclapi openapi -c . -o openapi.json

# Save YAML specification to file
hclapi openapi -c . -f yaml -o openapi.yaml
```
