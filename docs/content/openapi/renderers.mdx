# Interactive renderers

hclapi embeds four documentation viewers directly into the binary. You can mount them by adding a `docs` step to any route.

## Built-in renderers

### 1. Scalar

```hcl
route "GET /docs" {
  docs {
    renderer = "scalar"
    spec_url = "/openapi.json"
  }
}
```

### 2. Swagger UI

```hcl
route "GET /swagger" {
  docs {
    renderer = "swagger"
    spec_url = "/openapi.json"
  }
}
```

### 3. Redoc

```hcl
route "GET /redoc" {
  docs {
    renderer = "redoc"
    spec_url = "/openapi.json"
  }
}
```

### 4. Stoplight Elements

```hcl
route "GET /elements" {
  docs {
    renderer = "elements"
    spec_url = "/openapi.json"
  }
}
```

## Custom HTML templates

If you need custom branding or corporate navigation wrappers, point `template` to your own HTML file:

```hcl
route "GET /portal" {
  docs {
    template = "./templates/portal.html"
    spec_url = "/openapi.json"
    title    = "Developer Portal"
  }
}
```

## Template variables

Custom HTML templates use Go's standard `html/template` engine and have access to these variables:

| Variable         | Description                       | Example value      |
| :--------------- | :-------------------------------- | :----------------- |
| `{{ .Title }}`   | Configured document title         | `"Storefront API"` |
| `{{ .SpecURL }}` | Path to the OpenAPI specification | `"/openapi.json"`  |

An example minimal template:

```html
<!doctype html>
<html>
  <head>
    <title>{{ .Title }}</title>
  </head>
  <body>
    <h1>{{ .Title }}</h1>
    <p>
      Specification available at <a href="{{ .SpecURL }}">{{ .SpecURL }}</a>
    </p>
  </body>
</html>
```
